# 生命周期体系

uni-app 最容易混淆的知识点：**三套生命周期叠加**，而且钩子归属比原生小程序更隐蔽（页面同时是 Vue 组件）。

## 三套生命周期总览

| 层级 | 钩子 | 写在哪 |
|---|---|---|
| 应用级 | onLaunch / onShow / onHide / onError | 只在 `App.vue` |
| 页面级 | onLoad / onShow / onReady / onHide / onUnload / onPullDownRefresh / onReachBottom / onBackPress / onShareAppMessage | 只在 `pages.json` 注册的**页面** |
| 组件级 | Vue 标准：setup / created / mounted / unmounted | 所有普通组件 |

```js
// App.vue —— 应用生命周期 + 全局样式（Vue3 下无 template）
<script>
export default {
  onLaunch() {
    // 冷启动执行一次：恢复登录态、初始化全局配置
    const sessionId = uni.getStorageSync('sessionId')
    if (sessionId) this.initUser(sessionId)
  },
  onShow() {},  // 切前台（含从其他 App 切回）
  onHide() {},  // 切后台
}
</script>
<style> /* 全局样式 */ </style>
```

## 页面级钩子详解

```js
export default {
  onLoad(options) {
    // 页面加载，仅一次；options = 跳转 URL 的 query 参数
    // 首屏请求、参数解析放这里
  },
  onShow() {
    // 每次进入触发：首次 onLoad 之后、以及从其他页返回/切后台回来
    // "返回刷新"场景的标配（如地址页返回订单页回显新地址）
  },
  onReady() {},  // 首次渲染完成，可安全测量节点
  onHide() {},   // navigateTo 跳走 / 切后台
  onUnload() {}, // 页面销毁：清定时器、解绑 WebSocket/事件监听

  onPullDownRefresh() {
    // 需 pages.json 该页 style 配 "enablePullDownRefresh": true
    uni.stopPullDownRefresh()  // 处理完必须手动停
  },
  onReachBottom() {},  // 触底加载（距离 style.onReachBottomDistance）
  onBackPress() {
    // Android 物理返回/导航栏返回拦截；return true 阻止默认返回
    // 仅 App、H5、支付宝小程序支持，微信端不支持
  },
  onShareAppMessage() {},  // 微信转发，定义后菜单才有"转发"
}
```

### 页面时序（与原生小程序一致）

- 首次进入：`onLoad → onShow → onReady → (Vue 的 mounted 在 onReady 前)`
- 跳到新页：`本页 onHide → 新页 onLoad → onShow → onReady`
- 返回：`新页 onUnload → 本页 onShow`
- **执行顺序细节**：Vue 的 `beforeMount/mounted` 夹在 onLoad/onShow 与 onReady 之间——页面里两套钩子都能写，但"页面级"的语义（拿参数、返回刷新）只有页面钩子有。

## 组件里的注意点

- **页面级钩子在普通组件中不生效**（onLoad/onShow 写进组件等于死代码）。组件要感知所在页面显隐：父页面 onShow 传 props、或用全局事件（`uni.$on`）/ Pinia 状态。
- 组件清理用 Vue 的 `onUnmounted`（组合式）/ `unmounted`（选项式）。
- easycom 注册的组件同样遵守此规则。

## Composition API 写法（Vue3）

```js
import { onLoad, onShow, onPullDownRefresh } from '@dcloudio/uni-app'
import { onMounted, onUnmounted } from 'vue'

export default {
  setup() {
    onLoad((options) => { /* 拿路由参数 */ })
    onShow(() => { /* 返回刷新 */ })
    onPullDownRefresh(() => { uni.stopPullDownRefresh() })
    onMounted(() => {})
    onUnmounted(() => {})
  },
}
```

uni-app 官方包把页面级钩子做成了组合式函数，Vue3 项目推荐此写法（页面/组件钩子来源一目了然）。

## 经验提示

- 排查"为什么数据没刷新"先看钩子选对没有：返回页面不刷新 = 逻辑写在了 onLoad/mounted（只跑一次），应移到 onShow 并加条件。
- 登录态恢复放 App.vue 的 onLaunch + 首页 onShow 双保险：onLaunch 时 storage 已可读，但热启动（切回小程序）不触发 onLaunch。
- 旧代码里常见 `onLoad` 里发请求 + `onShow` 里也发的重复请求问题，用一个"首帧标记位"区分首次与回显。
