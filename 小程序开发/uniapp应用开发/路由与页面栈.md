# 路由与页面栈

## 没有路由库：pages.json + uni.* API

uni-app **没有 vue-router**（H5 端内部由运行时封装，但业务代码不接触）。路由 = `pages.json` 声明式注册 + `uni.*` 导航 API：

| API | 行为 | 对应小程序 | 限制 |
|---|---|---|---|
| `uni.navigateTo` | 保留当前页跳转 | wx.navigateTo | 非 tab 页；**栈上限 10 层** |
| `uni.redirectTo` | 关闭当前页跳转 | wx.redirectTo | 非 tab 页 |
| `uni.switchTab` | 跳 tab 页 | wx.switchTab | 仅 tabBar 页，不带 query |
| `uni.navigateBack({delta})` | 返回 | wx.navigateBack | — |
| `uni.reLaunch` | 关闭全部再打开 | wx.reLaunch | 任意页 |
| `uni.preloadPage` | 预加载页面 | — | 提升跳转速度 |

```js
uni.navigateTo({
  url: '/pages/order/index?from=cart',
  animationType: 'slide-in-right',
  events: { confirm(data) { /* 子页回传 */ } },
  success(res) { res.eventChannel.emit('init', { items: [] }) },
})
```

## 传参与取参

```js
// 目标页
export default {
  onLoad(options) {
    // options = { from: 'cart' } —— 全字符串
    const id = Number(options.id)
  },
}
```

- 复杂对象：JSON.stringify + encodeURIComponent 编码，onLoad 里反向解码；或改用全局状态（Pinia）/ EventChannel。
- `onLoad` 只跑一次，返回本页不重跑——带新参数回显用 onShow + 状态标记。
- **uni-app 没有 beforeRouteEnter 等路由守卫**；"未登录跳登录页"类需求在请求层拦截（401）或页面 onShow 检查登录态。

## EventChannel：页面间通信

与原生小程序同名机制，适合"选择器页"回传（选地址、选规格）：

```js
// 子页（被打开方）
onLoad() {
  const channel = this.getOpenerEventChannel()
  channel.on('init', (data) => { /* 父页初始数据 */ })
  channel.emit('confirm', { id: 42 })
}
```

替代方案对比：EventChannel（一次性的父子通信）／Pinia（跨页共享状态）／`uni.$emit/$on`（全局事件总线，注意 onUnload 时 `$off`，Vue3 下 EventBus 模式官方不推荐滥用）。

## 页面栈

```js
const pages = getCurrentPages()  // 栈实例数组，末位是栈顶
const prev = pages[pages.length - 2]
prev.$vm.setData?.(obj)  // 原生小程序写法
// uni-app Vue3 中拿组件实例：
prev.$vm.someState = newValue   // 直接改上一页实例的数据（慎用）
```

- 长链路防爆栈：深层跳转用 `redirectTo` 自替换；或 reLaunch 重置。
- 分享/扫码直达深层页时栈里只有自己，`navigateBack` 无处可退——兜底判断 `getCurrentPages().length === 1` 转 reLaunch 首页。

## 与 vue-router 的差异（Web 开发者速记）

| 维度 | vue-router | uni-app |
|---|---|---|
| 路由表 | 代码定义 createRouter | pages.json 配置 |
| 导航 | `<router-link>`、`router.push` | `uni.navigateTo` 等 API |
| 传参 | params/query/动态路由 | URL query + onLoad(options) |
| 守卫 | beforeEach/afterEach | 无（请求层拦截/页面自检替代） |
| 缓存 | keep-alive | 页面天然保留在栈中，无 keep-alive |
| 历史模式 | hash/history | 仅 H5 端 manifest.h5.router 可配，小程序无概念 |

## 经验提示

- 所有 URL 用绝对路径 `/pages/xxx/xxx`，别写相对路径（页面位置移动后相对路径会静默跳错）。
- 下拉刷新/触底加载与路由无关但常配对出现：`enablePullDownRefresh` 开在 pages.json 页面 style 里，不是全局开着到处生效。
