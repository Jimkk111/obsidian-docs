# 路由与页面栈

## 五个导航 API

| API | 行为 | 栈变化 | 限制 |
|---|---|---|---|
| `wx.navigateTo` | 保留当前页，跳转 | +1 | 目标不能是 tab 页；**栈上限 10 层** |
| `wx.redirectTo` | 关闭当前页，跳转 | 替换栈顶 | 目标不能是 tab 页 |
| `wx.switchTab` | 跳到 tabBar 页 | 清空全部非 tab 页 | 只能跳 pages.json 声明的 tab 页 |
| `wx.navigateBack` | 返回 | -delta | delta 默认 1，超过栈深回首页 |
| `wx.reLaunch` | 关闭所有页面再打开 | 重置为 1 | 任意页面（含 tab） |

选型口诀：前进用 navigateTo、提交成功后别让"返回"回到表单用 redirectTo、登录失效/重新开始用 reLaunch、回 tab 首页用 switchTab。

## 传参：URL query + onLoad(options)

```js
// 跳转
wx.navigateTo({ url: '/pages/detail/detail?id=42&from=cart' })

// 目标页
Page({
  onLoad(options) {
    // options = { id: '42', from: 'cart' } —— 全是字符串，注意转数字
  },
})
```

- query 值需 `encodeURIComponent`（含中文/特殊字符时）。
- **onLoad 只执行一次**：从 B 返回 A 时 A 的 onLoad 不再跑，需要新参数时用 `onShow` + 全局/事件方案。

## EventChannel：页面间双向通信

```js
// A → B 传参并监听 B 发回的事件
wx.navigateTo({
  url: '/pages/detail/detail?id=42',
  events: {
    selected(data) { console.log('B 回传', data) },
  },
  success(res) {
    res.eventChannel.emit('init', { from: 'A 的初始数据' })
  },
})

// B 页
Page({
  onLoad(options) {
    const channel = this.getOpenerEventChannel()
    channel.on('init', (data) => { /* A 传来的数据 */ })
    channel.emit('selected', { id: 42 })
  },
})
```

适合"选择器页"场景（选地址、选规格后回传），比全局 store 更内聚。

## 页面栈操作

```js
const pages = getCurrentPages()   // 页面栈实例数组，栈顶最后一个
const prev = pages[pages.length - 2]
prev.setData({ address: newAddress })  // 跨页改数据（能用但慎用，破坏数据流可读性）
```

- **10 层上限**：长链路（首页→分类→详情→规格→……）会被 navigateTo 打爆。深层级页面用 `redirectTo` 顶替自己，避免栈增长。
- 返回携带刷新：B 页 `wx.navigateBack()` 前可通过页面栈 `prev.setData` 或 EventChannel；更规范的是 A 在 `onShow` 里检查标记。

## 与 Web 路由（vue-router/react-router）的差异

| 维度 | Web SPA | 小程序 |
|---|---|---|
| 路由定义 | 代码里注册路由表 | `app.json`/`pages` 配置式声明 |
| 导航方式 | `<router-link>` / history.pushState | 五个 `wx.*` API，受栈模型约束 |
| 传参 | params/query/动态路由/状态管理 | URL query + onLoad(options) + EventChannel |
| 生命周期 | 组件级 | 应用/页面/组件三套（见逻辑层笔记） |
| 页面缓存 | keep-alive 可选 | 页面天然保留（出栈才销毁），无 keep-alive 概念 |

## 经验提示

- tabBar 页之间无法带参跳转（switchTab 不接受 query），参数走 storage/全局 store。
- 分享进入的小程序落地页可能就是深层页面（无页面栈历史），`navigateBack` 会退无可退——逻辑上要兜底 `getCurrentPages().length === 1` 时改用 reLaunch 回首页。
