更新性能：应用响应用户输入更新的速度，比如用户在搜索框输入文字列表更新搜索结果的速度、用户点击链接跳转到目标页面的速度。

# 优化手段

## （一）props稳定性

组件的props发生改变时会引起其更新。

如果把列表项的激活逻辑判断放在其内部处理，当activeId发生改变时，会引起所有的列表项处理，如下所示。

```vue

<ListItem
  v-for="item in list"
  :id="item.id"
  :active-id="activeId"
  />

```

但是如果将激活逻辑判断放在父组件处理，只传递布尔值给列表项，activeId发生改变只会引起少量组件的更新。

```vue

<ListItem
  v-for="item in list"
  :id="item.id"
  :active="activeId===item.id"
  />

```

这个例子启发我们，应该设计良好的props，比如减少props的取值、优化更新判断方式等等，从而避免无关的组件更新。
