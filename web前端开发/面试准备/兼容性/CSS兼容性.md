CSS的兼容性问题主要是不同浏览器的默认样式不一致、功能支持、浏览器前缀、盒模型差异等等。

**1.浏览器默认样式不一致**

不同浏览器对 HTML 元素的默认样式（如`margin`， `padding`， 字体大小）设定不同。这是引起跨浏览器差异最基本的原因。

解决方案：添加统一的默认样式。常用CSS Reset.css或者Nomarlize.css。二者的区别在于前者清除所有默认样式，由开发者完全自定义，适合高度定制化的设计，而后者保留有用的默认样式，仅修复浏览器不一致性，适合需要可访问性和一致性的项目。

**2.功能支持与浏览器前缀**

有些浏览器因为版本过低或者尚未适配而导致无法使用某个功能，解决方法是提供降级方案。

有些浏览器要使用某个功能，需要在属性名称前添加前缀，才能正常使用。带有前缀的属性代表这是一个实验性功能。

自动添加前缀的工具：Autoprefixer，集成到构建工具，根据设定的目标浏览器范围自动为属性添加前缀。

@support()用于查询浏览器是否支持某个功能，但这只能在支持@support()的浏览器上使用。

**3.盒模型差异**

设置一个元素的宽度为 width： 200px； padding： 10px； border： 1px solid black；。在标准浏览器下，实际占宽是 200 + 10*2 + 1*2 = 222px。但在老 IE 的 Quirks Mode（怪异模式）下，总宽度仍然是 200px，内容区域被挤压。

解决方案：始终使用 `<!DOCTYPE html>`：这会触发浏览器的标准模式，强制所有现代浏览器（包括 IE9+）遵循标准的 W3C 盒模型，消除最根本的差异；使用 `box-sizing: border-box`：这是目前的终极解决方案。它让元素的 `width` 和 `height` 包含 `padding` 和 `border`，更符合人类的直觉。
