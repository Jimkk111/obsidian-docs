**1.HTML语义化、SEO。**

HTML语义化是指我们在编写页面的时候，尽量使用有语义的标签来实现某个元素，这些有语义的标签有构建网页骨架的比如header表示头部、nav表示导航栏、main表示网页主体、aside表示侧边栏、section表示一个区域的不同节、footer表示网页的底部等等，还有表示特定含义的标签比如em表示强调、address表示地址等等。使用语义化的标签有利于实现无障碍功能以及对SEO友好。SEO是指搜索引擎优化，一种利用搜索引擎的内在规则、优化网站结构和内容从而提升网站在搜索结果中的自然排名的手段，本质是为了获得更高的网站曝光率。

**2.defer/async区别与页面渲染阻塞。**

defer和async是script标签的两个属性，用于控制外部脚本的加载与执行，从而影响页面的阻塞程度。

async脚本是异步下载的，不会阻塞HTML解析，但是一旦下载好，就会先停止HTML解析然后执行该脚本，执行完毕后恢复HTML解析。

defer脚本也是异步下载的，但是下载好之后不会立即执行，而是等待HTML完全解析完后，按照它们在HTML文档中的书写顺序依次执行，不会阻塞HTML的解析。

在遇到普通脚本时会立即停下HTML解析，加载该脚本并执行，会阻塞HTML解析，可能会导致白屏或内容延迟。

**如何实现垂直居中？**

文本的垂直居中，如果容器高度已知，可以设置行高等于容器高度。

如果行内有多个行内块元素，可以对需要垂直对齐的那个行内块元素设置vertical-align:middle。

flex和grid以及positon、table都可以实现垂直居中。首先是flex布局，在水平方向为主轴，容器设置align-items:middle；其次是grid布局，容器设置align-items:middle，或者给单个元素设置align-slef:middle。如果使用position，给父元素开启相对定位，子元素开启绝对定位，设置top:50%、transform:translate(0,-50%)；如果是表格布局，给父元素设置display:table-cell和vetical-align:middle，子元素即可垂直居中。
