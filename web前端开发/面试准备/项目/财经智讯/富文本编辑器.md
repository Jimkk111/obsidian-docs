项目的富文本编辑器基于tiptap实现。

## 一、tiptap

tiptap是基于ProseMirror实现的富文本编辑器框架。ProseMirror 是底层的编辑器引擎，Tiptap 在它上面包了一层更友好的 API。

**在vue中使用tiptap**

1.安装三个依赖，@tiptap/vue-3 、@tiptap/starter-kit 、@tiptap/pm

2.导入

```javascript

import { useEditor, EditorContent } from '@tiptap/vue-3'
import StarterKit from '@tiptap/starter-kit'

```

3.使用useEditor创建editor实例

useEditor的第一个参数，包含很多选项，extensions和content是最常用的，还有editorProps、onUpdate等选项。

```javascript

const editor = useEditor({
  extensions: [StarterKit],
  content: '<p>Hello World!</p>',
})

```

4.绑定到模板

```vue

<template>
  <EditorContent :editor="editor" />
</template>

```

<EditorContent/>是TipTap提供的vue组件，其实就是编辑器本身，被解析后的内容如下：

```html

<div contenteditable="true"         ← EditorContent 渲染的根元素
  class="tiptap ProseMirror"     ← 默认 class
  translate="no" role="textbox">
  <p>Hello</p>                      ← 你的内容
</div>

```

注意编辑器的两个类名。

5.添加更改样式的按钮。

```vue

<button
  v-if="editor"
  @click="editor.chain().focus().toggleBold().run()"
  :disabled="!editor.can().chain().focus().toggleBold().run()"
  :class="{ 'is-active': editor.isActive('bold') }">
  Bold
</button>

```

6.使用

给编辑器获取焦点，或者选中一部分文字，然后再点击某个样式的按钮即可。

# 二、面试回答

### S — 情境（Situation）

财经新闻平台需要一个功能完善的富文本编辑器，让编辑人员能够创作包含标题层级、加粗斜体、链接、图片、视频等丰富样式的新闻正文。市面上现成的编辑器要么过于臃肿，要么对中文输入支持不佳，且难以按业务需求定制节点类型和样式。

### T — 任务（Task）

我负责基于 Tiptap 从零构建富文本编辑系统，核心目标：

1. 提供标题、加粗、列表、引用、代码块、链接、图片、视频等完整的内容样式能力

2. 支持自定义节点拓展（如视频节点），满足财经新闻中嵌入多媒体内容的需求

3. 确保编辑体验流畅，特别是中文输入法的兼容性

4. 编辑器产出的 HTML 在阅读页能够以一致的样式渲染

### A — 行动（Action）

**编辑器核心搭建方面**，我选用 Tiptap（基于 ProseMirror）而非传统的 contenteditable 方案。原因在于 Tiptap 提供了声明式的扩展系统和可靠的 Schema 约束，能避免原生 contenteditable 常见的光标错位和格式污染问题。在 TiptapEditor.vue 中，通过 `useEditor()` 组合式 API 配置了 StarterKit（开箱即用的加粗、斜体、H1-H3、有序/无序列表、引用块、代码块、分割线、撤销/重做），并叠加了 Image、Link、Placeholder 三个官方扩展。

**自定义视频节点方面**，因为 Tiptap 官方没有内置视频支持，我通过 `Node.create()` 自定义了一个名为 `video` 的块级原子节点（TiptapEditor.vue 内联定义）。该节点配置了 `atom: true`（不可编辑内部内容）、`draggable: true`（可拖拽排序），通过 `parseHTML` 和 `renderHTML` 实现 HTML 与编辑器内部状态的互转，最终渲染为带 `controls` 属性的原生 `<video>` 元素。图片和视频上传分别对接后端 API，限制了文件类型和大小（图片 5MB、视频 100MB），上传期间工具栏按钮切换为加载动画。

**中文输入法兼容方面**，这是实际开发中最棘手的问题。CJK 输入法在组合输入（composition）阶段会多次触发 `onUpdate`，导致拼音中间态被当作 HTML 标签片段写入内容。我通过监听编辑器的 `compositionstart` 和 `compositionend` DOM 事件，在组合输入期间设置标志位 `isComposing`，`onUpdate` 回调检测到该标志后直接跳过，只在组合结束后才同步内容，从根本上解决了中文输入导致的格式错乱。

**数据流设计方面**，编辑器通过 `v-model` 与父组件双向绑定 HTML 字符串。在 `onUpdate` 中调用 `getHTML()` 向上 emit，同时 watch `modelValue` prop 通过 `setContent(val, { emitUpdate: false })` 向下同步。这里设置了一个 `updatingFromEditor` 防护标志位，避免编辑器的本地更新触发 watch 后再反向写入编辑器，形成无限循环。

**样式体系方面**，我将编辑器内和阅读页的样式统一收敛到 tiptap.css，全局引入。这套样式覆盖了段落（首行缩进 2em，符合中文排版习惯）、各级标题、引用块左侧边框、代码块深色背景、图片圆角、链接蓝色下划线等。新闻详情页只需在渲染 `v-html` 的容器上加 `class="tiptap"` 即可获得一致的视觉效果。同时编写了 `formatContent()` 兜底函数，对旧数据的纯文本内容自动转换为 `<p>` 段落格式，保证了历史数据兼容。

**草稿与发布流程方面**，在 NewsEditor.vue 中将编辑器与封面图上传、分类选择、标签选择组合为完整的新闻发布页，实现了 30 秒间隔的自动存草稿机制，支持从草稿恢复编辑和一键发布。

### R — 结果（Result）

最终交付了一个功能完备的富文本编辑系统，涵盖 10+ 种内容样式、图片/视频多媒体嵌入、中文输入完美兼容、自动草稿保存、以及编辑端与阅读端样式一致的渲染体验。编辑器与新闻发布流程无缝集成，编辑人员可以像使用 Word 一样直观地创作财经新闻内容。

---

**面试追问预判**：

- **为什么选 Tiptap 而不是 Quill/Slate？** — Tiptap 基于 ProseMirror，Schema 约束严格，扩展系统更灵活（自定义 Node/Mark 只需 `Node.create()`）；Quill 用 Delta 格式，自定义块级节点较麻烦；Slate 偏底层，需要手写更多逻辑。

- **视频节点的**`atom: true`**是什么意思？** — 原子节点表示该节点内部不可编辑，光标无法进入，整体作为一个不可分割的单元，适合图片、视频、iframe 等嵌入内容。

- `emitUpdate: false`**的作用？** — Tiptap 的 `setContent` 默认会触发 `onUpdate`，传入 `{ emitUpdate: false }` 阻止这次触发，避免外部分发的更新又被当作新的编辑操作 emit 回去，形成死循环。
