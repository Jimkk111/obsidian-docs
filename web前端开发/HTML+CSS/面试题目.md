**6. `<script>` 的 defer 和 async 有什么区别？（含页面渲染阻塞）**

defer和async是script标签的两个属性，用于控制外部脚本的加载与执行，从而影响页面的阻塞程度。

async脚本是异步下载的，不会阻塞HTML解析，但是一旦下载好，就会先停止HTML解析然后执行该脚本，执行完毕后恢复HTML解析。

defer脚本也是异步下载的，但是下载好之后不会立即执行，而是等待HTML完全解析完后，按照它们在HTML文档中的书写顺序依次执行，不会阻塞HTML的解析。

在遇到普通脚本时会立即停下HTML解析，加载该脚本并执行，会阻塞HTML解析，可能会导致白屏或内容延迟。

### 2. 语义化与可访问性

**8. 讲一下HTML语义化**

HTML语义化是指使用有语义的标签比如header、nav、asider、main、footer、em而不是div、span等无语义的标签来构建网页，不仅可以提高代码的可读性，也能优化SEO以及提高无障碍访问能力。

> [!note] 版本二（原「HTML&CSS（手写版）」，含 SEO）
> HTML语义化是指我们在编写页面的时候，尽量使用有语义的标签来实现某个元素，这些有语义的标签有构建网页骨架的比如header表示头部、nav表示导航栏、main表示网页主体、aside表示侧边栏、section表示一个区域的不同节、footer表示网页的底部等等，还有表示特定含义的标签比如em表示强调、address表示地址等等。使用语义化的标签有利于实现无障碍功能以及对SEO友好。SEO是指搜索引擎优化，一种利用搜索引擎的内在规则、优化网站结构和内容从而提升网站在搜索结果中的自然排名的手段，本质是为了获得更高的网站曝光率。

## 二、CSS

### 1. 基础与选择器

**20. CSS 选择器有哪些？优先级如何计算？哪些属性可以继承？**

CSS选择器可以分为以下5大类：

（1）基础选择器：通配符选择器、标签选择器、类选择器、ID选择器。

（2）关系选择器：后代选择器、子选择器、相邻兄弟选择器、通用兄弟选择器。

（3）伪类选择器：动态伪类比如:hover、:active、:focus，结构伪类比如:first-child、:last-child、:nth-child(n)、:nth-of-type()，否定伪类:not()，还有表示根元素的:root，表示无子元素的元素:empty。

（4）伪元素选择器：作用是创建虚拟元素，包含::before、::after、::first-line、::first-letter等等。

（5）属性选择器：用一对中括号包裹着一个属性名，或者同时指定属性名对应的属性值，比如[type="text"]，选择输入框。

优先级按从高到底排序为!import、内联样式、ID选择器、类选择器和伪类选择器和属性选择器、元素选择器和伪元素选择器、通配符选择器和关系选择器和否定伪类自身、继承的属性。

元素可以继承的属性主要为字体类（比如font-size、font-family、font-style等等）、文本类（比如color、text-indent、letter-spacing、text-decoration等）、列表类（比如list-style、list-style-position等等）的属性，不可继承的属性主要与盒模型、定位以及背景相关。

### 2. 盒模型与 BFC

**26. 说一下盒模型（标准盒模型与怪异盒模型）**

盒模型是对网页单个元素结构的抽象化表示，使用盒模型表示的元素看起来就像是一个盒子。盒模型的要素包括外边距、内边距、边框、内容区。根据计算尺寸的方式的不同，盒模型可以分为标准盒模型、怪异盒模型。设置标准盒模型的方式："box-sizing: conten-box"，盒子的大小只根据内容区计算；设置怪异盒模型的方式："box-sizing: border-box"，盒子的大小包括：边框、内边距、内容区。 

> [!note] 版本二（原「HTML&CSS（标准版）」）
> 盒模型是浏览器对页面元素的结构的形象化表示。每个元素在页面上就好像表现为一个矩形的盒子，从里到外分别是内容区、内边距、边框和外边距。内容区存放实际的内容，宽度和高度默认控制的是这块区域；内边距是边框和内容区之间的透明区域；边框是包裹在内边距外面的实线或虚线框，可以设置粗细、样式和颜色；外边距位于盒子最外层，用于控制当前盒子与相邻盒子之间的间距，也是透明的。
>
> 盒模型分为标准盒模型和怪异盒模型，通过设置盒子的box-sizing属性自由切换两种模型。box-sizing:content-box为标准盒模型，这是默认值；box-sizing:border-box是怪异盒模型。二者的主要区别是计算width和height的方式不同。标准盒模型的width和height只包含内容区；怪异盒模型的width和height包含内容区+内边距+边框。理解这两种盒子模型有利于更精准地控制元素的位置和尺寸，避免莫名溢出的问题。

### 3. 尺寸单位与响应式

**30. 说一下CSS的尺寸单位**

px，全称pixel，CSS像素单位，不是指物理像素。

em，如果font-size的值使用该单位，表示父元素的字体大小；如果是其他属性的值使用该单位，表示自身的字体大小。

rem，文档根元素的字体大小。

vw，相对单位，相对于视口宽度的百分之一；vh，相对单位，相对于视口高度的百分之一。

vw和em、rem常搭配使用实现响应式布局。元素的尺寸、边距的单位设置为em，字体大小的单位设置为rem，文档根元素字体大小的单位设置为vw，这样再使用媒体查询，在小设备下使用更小的字体大小，并且元素的尺寸、边距也将同步变小，实现页面适应屏幕大小。

**42. 讲一下浮动**

浮动是让元素脱离正常文档流的方式之一，开启了浮动的元素就好像浮在了网页上一样，可以实现文字环绕图片的效果，但实际上更多被用来布局网页。 浮动元素有以下特点：宽度不包含在父元素上，即盒子塌陷现象；影响其他元素的正常排版。 开启浮动的方式："display:flow" 清除浮动的方法：1."clear:both"，单独标签（不推荐）或伪元素（常用）；2.给父元素添加"overflow:hidden" ，原理是开启BFC；3.给父元素添加“display: flow-root”
