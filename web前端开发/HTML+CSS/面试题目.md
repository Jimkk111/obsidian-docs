### 2. 盒模型与 BFC

**26. 说一下盒模型**

盒模型是对网页单个元素结构的抽象化表示，使用盒模型表示的元素看起来就像是一个盒子。盒模型的要素包括外边距、内边距、边框、内容区。根据计算尺寸的方式的不同，盒模型可以分为标准盒模型、怪异盒模型。设置标准盒模型的方式："box-sizing: conten-box"，盒子的大小只根据内容区计算；设置怪异盒模型的方式："box-sizing: border-box"，盒子的大小包括：边框、内边距、内容区。

**28. 说一下BFC**

BFC的中文表示是块级格式上下文，是一块独立的渲染区域。BFC内元素设置的外边距不会影响到外界，常用来解决外边距折叠问题。开启BFC的方法有：设置内边距、设置边框、开启"Overflow:hidden"

### 3. 尺寸单位与响应式

**30. 说一下CSS的尺寸单位**

px，全称pixel，CSS像素单位，不是指物理像素。

em，如果font-size的值使用该单位，表示父元素的字体大小；如果是其他属性的值使用该单位，表示自身的字体大小。

rem，文档根元素的字体大小。

vw，相对单位，相对于视口宽度的百分之一；vh，相对单位，相对于视口高度的百分之一。

vw和em、rem常搭配使用实现响应式布局。元素的尺寸、边距的单位设置为em，字体大小的单位设置为rem，文档根元素字体大小的单位设置为vw，这样再使用媒体查询，在小设备下使用更小的字体大小，并且元素的尺寸、边距也将同步变小，实现页面适应屏幕大小。

**42. 讲一下浮动**

浮动是让元素脱离正常文档流的方式之一，开启了浮动的元素就好像浮在了网页上一样，可以实现文字环绕图片的效果，但实际上更多被用来布局网页。 浮动元素有以下特点：宽度不包含在父元素上，即盒子塌陷现象；影响其他元素的正常排版。 开启浮动的方式："display:flow" 清除浮动的方法：1."clear:both"，单独标签（不推荐）或伪元素（常用）；2.给父元素添加"overflow:hidden" ，原理是开启BFC；3.给父元素添加“display: flow-root”
