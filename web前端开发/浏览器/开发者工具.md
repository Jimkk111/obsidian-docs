# 开发者工具（DevTools）

打开方式：`F12` 或 `Ctrl+Shift+I`（Mac 为 `Cmd+Opt+I`）。按面板分类整理，高频调试场景：**Elements 调样式、Sources 调 JS、Network 看请求、Performance 查卡顿**。

## 1.Elements（元素面板）

### （1）查看与编辑DOM

- 实时查看页面DOM结构，双击可直接编辑节点文本/属性（仅影响当前页面，刷新即恢复）；
- `Ctrl+F` 在DOM树中按选择器/文本搜索；
- 右键节点：`Force state`（强制伪类状态）、`Add attribute`、`Edit as HTML`、`Delete element`、`Scroll into view`、`Copy → Copy selector / Copy JS path`（生成定位该节点的CSS选择器或JS路径）。

### （2）查看与调试CSS

- **Styles**：查看元素匹配的所有CSS规则，包括层叠来源（内联、样式表、用户代理样式表），划掉的规则表示被更高优先级覆盖；可直接增删改样式实时预览；
- **Computed**：查看最终计算后的样式值，勾选"Show all"显示全部属性；点击属性旁箭头可跳到Styles中的来源；
- **盒模型图**：直观查看 margin/border/padding/content 各区域的实际尺寸；
- **强制伪类状态**：勾选 `:hover`、`:active`、`:focus` 等可调试仅在这些状态下生效的样式；
- **布局调试**：Flexbox/Grid 容器会有覆盖层图标，点击可显示网格线、间距、对齐情况。

### （3）DOM断点

在节点右键 → Break on，可设置三种DOM变更断点：

- **subtree modifications**：子树节点增删改时暂停；
- **attribute modifications**：该节点属性变化时暂停（定位"谁改了我的样式/属性"很有用）；
- **node removal**：节点被移除时暂停。

## 2.Console（控制台）

### （1）常用日志API

```js
console.log()            // 常规输出，支持占位符 %s %d %c（%c可加CSS样式）
console.error/warn()     // 错误/警告，带堆栈，会显示在Issues/错误计数
console.table(arr/obj)   // 以表格展示数组和对象，适合对比数据
console.dir(obj)         // 以对象树形式展开（查看DOM元素的对象属性时用，而非HTML结构）
console.time('t') / timeEnd('t')   // 计时，测量一段代码耗时
console.group('g') / groupEnd()    // 日志分组折叠
console.count('x')       // 计数器，统计某处执行次数
console.trace()          // 打印当前调用堆栈
console.assert(cond, msg) // 条件为假时才输出
```

### （2）控制台内置的快捷变量与方法

| 表达式 | 含义 |
| --- | --- |
| `$0`～`$4` | 最近在Elements中选中的元素（$0是最后一个） |
| `$(sel)` / `$$(sel)` | 等价于 `querySelector` / `querySelectorAll` |
| `$x(xpath)` | 按XPath查询元素 |
| `copy(obj)` | 复制到剪贴板（复制大JSON响应常用） |
| `inspect(obj)` | 在Elements/_sources面板中定位该对象 |
| `monitorEvents(el, 'click')` | 监控元素的事件触发 |
| `debug(fn)` / `undebug(fn)` | 在函数第一行自动加断点 |

### （3）过滤与设置

- 顶部过滤器可按级别（Info/Warnings/Errors）筛选，`Ctrl+K`搜索；
- 勾选 `Preserve log` 在页面跳转时保留日志；勾选 `Log XMLHttpRequests` 打印所有AJAX请求。

## 3.Sources（源代码面板）——断点调试

### （1）断点

程序暂停执行的地方。注意：被添加断点的语句，**执行到该处时该语句还未执行**（暂停在语句之前）。断点有多种类型（见下文）。

### （2）调试执行控制

| 快捷键 | 操作 | 说明 |
| --- | --- | --- |
| `F8` | 继续（Resume） | 从当前断点执行到下一个断点 |
| `F10` | 跨越（Step over） | 单步执行，遇到函数调用直接执行完，**不进入**函数内部 |
| `F11` | 步进（Step into） | 单步执行，遇到函数调用**进入**函数内部逐行执行 |
| `Shift+F11` | 步出（Step out） | 在函数内部时，执行完函数剩余代码并跳出（注意不是F12，F12是打开DevTools） |

辅助按钮：Step（逐行，不区分函数）、Deactivate breakpoints（禁用所有断点）、Pause on exceptions（抛异常时暂停，可勾选"仅未捕获异常"）。

### （3）断点类型

- **行断点**：直接点击行号添加；
- **条件断点**：右键行号 → Add conditional breakpoint，输入条件表达式，仅在条件为真时暂停（调试循环时必用）；
- **日志点（Logpoint）**：右键行号 → Add logpoint，不停顿只输出日志，效果等同插入console.log且不改动代码；
- **DOM断点**：在Elements中设置（见1.3）；
- **事件监听断点**：Sources右侧 Event Listener Breakpoints，勾选如 `Mouse → click`，任何click事件处理执行前暂停；
- **XHR/fetch断点**：URL包含指定关键字时暂停，定位"谁发的这个请求"；
- **Debugging框架代码**：可用 Blackbox（忽略指定脚本）跳过第三方库代码。

### （4）Watch、调用栈与作用域

- **Watch**：添加表达式持续观察其值随执行的变化；
- **Call Stack**：查看当前暂停时的函数调用链，点击任意一帧可跳到该帧的执行上下文（做"逆行"排查）；
- **Scope**：Local / Closure / Global 各作用域中的变量实时值；
- 代码区域下方 **Breakpoints** 列表管理所有断点，**Snippets** 可保存常用调试脚本（`Ctrl+Enter`运行）。

### （5）调试信息分析

在Watch中查看框架状态：如Vue项目中可观察 `vm.$data`；Vuex/Pinia项目可查看 `store.state` 来了解状态结构。也可在Console中直接访问（需将实例暴露到window，或使用Vue Devtools插件）。

## 4.Network（网络面板）

### （1）请求列表

每行显示：Name（名称）、Status（状态码）、Type（资源类型）、Initiator（发起者，定位是谁触发的请求）、Size（传输大小/解压后大小）、Time、Waterfall（时间线）。点击请求可查看：

- **Headers**：请求/响应头、查询参数、General中的请求方法与URL；
- **Payload**：POST请求体；
- **Preview / Response**：响应内容预览；
- **Initiator**：发起该请求的调用堆栈；
- **Timing**：请求各阶段耗时明细。

### （2）Timing各阶段含义（面试常问）

- **Queueing**：请求排队（浏览器并发限制：HTTP/1.1同域名6个连接）；
- **Stalled**：等待发送（代理协商、连接复用前的等待）；
- **DNS Lookup / Initial connection / SSL**：域名解析、TCP握手、TLS协商；
- **Request sent**：发出第一个字节；
- **Waiting (TTFB)**：等待服务器首字节返回，**时间过长说明服务端慢**；
- **Content Download**：下载响应体，**过长说明资源太大或带宽不足**。

### （3）过滤、搜索与模拟

- 按类型过滤：XHR、JS、CSS、Img、Media、Font、Doc、WS等；
- `Ctrl+F` 全局搜索请求内容；可勾选 `Preserve log`（跳转不丢失）、`Disable cache`（禁用缓存）、`Hide data URLs`；
- **Throttling（节流模拟）**：Fast 3G / Slow 3G / 自定义，模拟弱网测试加载表现和"白屏"问题。

### （4）实用操作

- 右键请求：`Copy → Copy as fetch / Copy as cURL`（生成可重放的请求代码，调试接口必用）；
- `Replay XHR`：重新发送该请求；`Block request URL`：模拟资源加载失败；
- 导出/导入 HAR 文件用于离线分析或提交性能问题报告；
- **Overriding**：可本地覆盖（重写）服务器返回的响应内容进行调试。

## 5.Performance（性能面板）

### （1）录制与分析

点击录制 → 操作页面 → 停止，得到时间线报告：

- **Overview区**：FPS（帧率）、CPU（各任务类型占比，黄色=脚本）、NET（网络）；
- **主线程火焰图**：查看函数调用树，**红色的红色三角形标记"Long Task"（超过50ms的长任务）**；紫色=渲染（Layout）、绿色=Paint；
- **Interactions / Frames**：交互延迟与每帧渲染情况。

### （2）常见性能问题定位

- 掉帧卡顿：看FPS曲线低谷处的火焰图，找长任务（往往是长JS计算或强制同步布局）；
- 页面加载慢：结合 Network 与 Main 通道，分析关键渲染路径是否被阻塞；
- 内存问题：配合 Memory 面板做堆快照对比（查内存泄漏）。

## 6.Application（应用面板）

- **Storage**：查看和编辑 Local Storage、Session Storage、IndexedDB、Web SQL、Cookies（可清除站点数据，Clear site data）；
- **Service Workers**：查看注册的SW、模拟离线（Offline）、触发push/sync；
- **Cache Storage / Cache**：查看Cache API缓存内容；
- **Manifest**：查看PWA清单配置；
- **Back/forward cache**：检测页面是否可被浏览器bfcache缓存。

## 7.其他面板

- **Memory**：堆内存快照（Heap snapshot）、分配时间线，用于排查内存泄漏（常见：未解绑的事件监听、闭包、定时器、游离DOM）；
- **Lighthouse**：一键生成性能、可访问性、最佳实践、SEO审计报告，并给出优化建议；
- **Security**：查看HTTPS证书与混合内容问题；
- **Rendering**：开启"绘制闪烁"（Paint flashing，绿色高亮发生重绘的区域）、"Layout Shift Regions"（蓝色高亮发生布局偏移的区域，排查CLS）、FPS仪表；
- **Sensors**：模拟地理位置、设备方向、网络类型；
- **Device Mode**（顶部手机图标）：模拟不同设备分辨率、DPR、触摸事件。

## 8.常用快捷键汇总

| 快捷键 | 作用 |
| --- | --- |
| `F12` / `Ctrl+Shift+I` | 打开/关闭 DevTools |
| `Ctrl+Shift+C` | 元素检查模式（点击页面元素定位到DOM） |
| `Ctrl+Shift+J` | 直接打开Console面板 |
| `Ctrl+R` / `Ctrl+Shift+R` | 刷新 / 强制刷新（忽略缓存） |
| `F8` | 继续执行到下一断点 |
| `F10` / `F11` / `Shift+F11` | 单步跳过 / 步入 / 步出 |
| `Ctrl+Shift+P` | 打开命令菜单（可搜到几乎所有的隐藏功能） |
