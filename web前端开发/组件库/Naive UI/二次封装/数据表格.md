### 2026-09-06 DataTable 落地实现与踩坑（苍穹外卖 Vue3 重构）

**背景**：7 个列表页各自手写 n-data-table 的分页/loading/数据获取，逻辑重复。按"columns + reqFn + params"思路封装 DataTable.vue 并全量接入（远程模式 6 处 + 本地模式 1 处）。

**好处**：
- 分页/loading/数据获取收敛进组件，页面只剩 columns 定义 + 筛选参数；
- 全局行为（空态、分页档位、loading）一处修改全部生效；
- 泛型 SFC（`generic="T"`）让 columns/reqFn/data 全链路类型化；
- 与 useTable 这类逻辑 hook 二选一，避免叠加。

**踩坑与解决**：

1. **`ref(props.xxx)` 响应性断裂**：草稿里 `tableData = ref(props.data)` 只在创建时取一次值，父组件重新查询后表格不更新。修法：远程模式数据由组件内部持有（不是 props 拷贝），本地模式直接透传 props。
2. **泛型约束与 interface 冲突**：`T extends Record<string, unknown>` 下，TS 的 interface 没有隐式索引签名不满足约束。修法：业务项类型从 `interface` 改为 `type` 别名（type 有隐式索引签名）。
3. **泛型组件取 ref 类型**：`ref<InstanceType<typeof DataTable>>` 直接报错。解法：约定 `DataTableExpose` 接口（search/tableData）给页面声明。
4. **插槽透传**：包装组件用 `v-for="(_, name) in $slots"` + 动态具名插槽逐个转发（empty/summary 等）；普通属性用 `inheritAttrs: false` + `v-bind="$attrs"`。
5. **给页面的回调能力**：`defineExpose({ search, tableData })`，search 返回 Promise——订单页"处理完自动跳转下一条"靠 await 后读 tableData 实现。
6. **字段契约**：后端分页返回 `{ records, total }`，草稿里写成 `res.record`（少个 s）直接取不到数据；reqFn 约定返回解包后的 PageData，axios response 的解包在页面 fetcher 里做。

**关键代码**（双模式核心）：

```vue
<n-data-table
  :data="isRemote ? tableData : (data ?? [])"
  :columns="columns"
  :remote="isRemote"
  :loading="isRemote && loading"
  :pagination="isRemote ? pagination : undefined"
  v-bind="$attrs"
/>
<script setup lang="ts" generic="T extends Record<string, unknown>">
const isRemote = computed(() => !!props.reqFn)
const search = (resetPage = false) => {
  if (!isRemote.value) return Promise.resolve()
  if (resetPage) page.value = 1
  return fetchData()
}
defineExpose({ search, tableData })
</script>
```
