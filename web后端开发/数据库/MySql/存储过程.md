# 存储过程

存储过程（Stored Procedure）是**预先编译并存储在数据库服务端**的一组 SQL 语句集合（官方 25 章 Stored Objects，同类对象还有存储函数、触发器、事件）。调用时一次网络请求执行整段逻辑，无需重复传输和解析 SQL。

优缺点：

- 优点：复用封装、减少网络交互次数、执行效率相对稳定。
- 缺点：逻辑耦合在数据库端，难调试、难版本管理、难水平扩展；高并发下所有压力集中到数据库。
- **互联网规范（如《阿里巴巴 Java 开发手册》）明确禁止使用存储过程**，业务逻辑应放在应用层；但面试与遗留系统维护仍需掌握。

## 一、基本语法

命令行客户端中，过程体内以 `;` 结尾的语句会被提前截断，需先用 `DELIMITER` 临时更换语句结束符：

```sql
DELIMITER $$                                  -- 把结束符改为 $$
CREATE PROCEDURE p1(IN score INT, OUT result VARCHAR(10))
BEGIN
    IF score >= 60 THEN
        SET result = '及格';
    ELSE
        SET result = '不及格';
    END IF;
END$$
DELIMITER ;                                   -- 恢复为 ;

CALL p1(85, @r);                              -- 调用，@r 接收 OUT 参数
SELECT @r;                                    -- 及格
```

参数三种模式：`IN` 输入（默认）、`OUT` 输出、`INOUT` 既输入又输出。

```sql
SHOW PROCEDURE STATUS WHERE db = 'sky';       -- 查看指定库的过程
SHOW CREATE PROCEDURE p1;                     -- 查看定义
DROP PROCEDURE [IF EXISTS] p1;                -- 删除
```

## 二、变量

```sql
-- 局部变量：必须写在 BEGIN 内最前面
DECLARE i INT DEFAULT 1;
SET i = i + 1;

-- 用户变量（会话级，@ 开头，可在过程内外传递）
SET @cnt = 0;
SELECT COUNT(*) INTO @cnt FROM emp;           -- 查询结果赋给变量
```

`SELECT ... INTO` 要求结果恰好一行一列，否则报错。

## 三、条件与循环

```sql
-- IF
IF 条件1 THEN ...
ELSEIF 条件2 THEN ...
ELSE ...
END IF;

-- CASE
CASE 变量 WHEN v1 THEN ... WHEN v2 THEN ... ELSE ... END CASE;

-- WHILE（先判断后执行）
WHILE i <= 10 DO
    SET i = i + 1;
END WHILE;

-- REPEAT（先执行后判断，至少执行一次）
REPEAT
    SET i = i + 1;
UNTIL i >= 10 END REPEAT;

-- LOOP（死循环，配合 LEAVE 跳出 / ITERATE 跳过本次）
myloop: LOOP
    SET i = i + 1;
    IF i >= 10 THEN LEAVE myloop; END IF;
END LOOP myloop;
```

## 四、游标（游动指针）

逐行处理查询结果集（相当于结果集上的迭代器）。游标变量必须在普通变量之后声明，并用 handler 处理取完的 NOT FOUND：

```sql
DELIMITER $$
CREATE PROCEDURE batch_pay()
BEGIN
    DECLARE e_id INT;
    DECLARE done INT DEFAULT 0;
    DECLARE cur CURSOR FOR SELECT id FROM emp;               -- 声明游标
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = 1;     -- 取尽时置标记

    OPEN cur;                                                -- 打开
    read_loop: LOOP
        FETCH cur INTO e_id;                                 -- 逐行取值
        IF done = 1 THEN LEAVE read_loop; END IF;
        UPDATE emp SET salary = salary + 500 WHERE id = e_id;
    END LOOP;
    CLOSE cur;                                               -- 关闭
END$$
DELIMITER ;
```

## 五、条件处理程序（Handler）

捕获执行中的异常或状态：

```sql
DECLARE EXIT HANDLER FOR SQLEXCEPTION
    SELECT '执行出错，事务已回滚';            -- 触发后退出
-- 常用：NOT FOUND（无行/游标取尽）、SQLEXCEPTION（错误）、SQLWARNING（警告）
-- 动作：CONTINUE 继续执行 / EXIT 退出
```
