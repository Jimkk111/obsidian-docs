# 多表查询

多表查询指在一条 SQL 中同时查询多张关联表（官方手册 13.2.10.7 JOIN、13.2.10 子查询部分）。

## 一、多表关系设计

业务中的表间关系通过外键字段建模：

- **一对多（多对一）**：如部门与员工。在「多」的一方（员工表）加 `dept_id` 外键字段指向「一」的一方。
- **多对多**：如学生与课程。需要**中间表**（选课表）至少包含两方的主键作为外键。
- **一对一**：如用户与用户详情。多用于表拆分，在任意一方加唯一外键（`UNIQUE`）指向另一方主键。

## 二、连接查询

直接 `FROM a, b` 会产生**笛卡尔积**（两表所有行的任意组合，n×m 条），需要用连接条件消除无效组合。

### 1. 内连接（INNER JOIN）

查询两张表**交集**部分：同时满足连接条件的记录。

```sql
-- 显式内连接（推荐）
SELECT e.name, d.name
FROM emp e
INNER JOIN dept d ON e.dept_id = d.id;

-- 隐式内连接（旧写法）
SELECT e.name, d.name
FROM emp e, dept d
WHERE e.dept_id = d.id;
```

### 2. 外连接（OUTER JOIN）

- **左外连接**：查询左表全部 + 两表交集（右表无匹配的字段补 NULL）。
- **右外连接**：查询右表全部 + 两表交集。

```sql
SELECT e.name, d.name
FROM emp e
LEFT OUTER JOIN dept d ON e.dept_id = d.id;   -- OUTER 可省略

SELECT e.name, d.name
FROM emp e
RIGHT JOIN dept d ON e.dept_id = d.id;
```

MySQL 不支持 `FULL OUTER JOIN`，可用左连接 UNION 右连接模拟满外连接。

### 3. 自连接（Self Join）

一张表和自己连接，**必须起别名**区分。如查询「每个员工及其上级」：

```sql
SELECT e.name AS 员工, m.name AS 领导
FROM emp e
LEFT JOIN emp m ON e.manager_id = m.id;
```

## 三、联合查询（UNION）

把多条 SELECT 的结果纵向合并为一个结果集：

```sql
SELECT name FROM emp WHERE age < 30
UNION
SELECT name FROM emp WHERE dept_id = 3;
```

- `UNION` 会**去重**并排序；`UNION ALL` 不去重、性能更好，能确定无重复时优先使用。
- 各查询的**列数和顺序和名称必须一致**，类型需要兼容。
- 等价于 `WHERE age < 30 OR dept_id = 3` 的场景，UNION 可利用两个条件的索引（OR 通常走不了）。

## 四、子查询

子查询（Subquery）：SQL 语句中嵌套的另一条 SELECT 语句。根据结果形式分为几类：

### 1. 标量子查询

子查询返回**单个值**（一行一列），可出现在 `=`、`>` 等比较运算符之后。

```sql
-- 查询入职时间早于「张三」的员工
SELECT * FROM emp
WHERE entrydate < (SELECT entrydate FROM emp WHERE name = '张三');
```

### 2. 列子查询

子查询返回**一列多行**，配合 `IN`、`NOT IN`、`ANY`、`ALL` 使用：

| 操作符 | 说明 |
| ---- | ---- |
| IN | 在集合中 |
| NOT IN | 不在集合中 |
| ANY / SOME | 与集合中**任意一个**比较成立即可（= ANY 等价于 IN） |
| ALL | 与集合中**所有**比较都成立才可（<> ALL 等价于 NOT IN） |

```sql
SELECT * FROM emp
WHERE dept_id IN (SELECT id FROM dept WHERE name = '教研部' OR name = '咨询部');
```

### 3. 行子查询

子查询返回**一行多列**，用 `=` 或 `IN` 与行构造器比较：

```sql
SELECT * FROM emp
WHERE (salary, manager_id) = (SELECT salary, manager_id FROM emp WHERE name = '张三');
```

### 4. 表子查询

子查询返回**多行多列**，作为一张临时表参与查询，常放在 FROM 后：

```sql
SELECT e.* FROM emp e
JOIN (SELECT dept_id, AVG(salary) avg_sal FROM emp GROUP BY dept_id) t
  ON e.dept_id = t.dept_id AND e.salary > t.avg_sal;   -- 高于本部门平均薪水的员工
```

### 5. EXISTS 子查询

判断子查询是否有结果，返回 TRUE / FALSE，常用于相关子查询（子查询引用了外层表的字段）：

```sql
SELECT * FROM dept d
WHERE EXISTS (SELECT 1 FROM emp e WHERE e.dept_id = d.id);   -- 有员工的部门
```

> 补充：MySQL 8.0 支持公共表表达式 `WITH cte AS (SELECT ...) SELECT ... FROM cte;`，可替代 FROM 后的表子查询，多次引用时更清晰。
