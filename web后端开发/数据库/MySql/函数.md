# 常用函数

MySQL 内置函数（官方手册第 12 章 Functions and Operators）按用途分为字符串、数值、日期、流程控制四类。聚合函数见 [[web后端开发/数据库/MySql/DQL|DQL]]。

## 一、字符串函数

| 函数 | 说明 |
| ---- | ---- |
| CONCAT(s1, s2, ...) | 拼接字符串，任一参数为 NULL 则结果为 NULL |
| CONCAT_WS(sep, s1, s2, ...) | 以指定分隔符拼接，忽略 NULL |
| UPPER(s) / UCASE(s) | 转大写 |
| LOWER(s) / LCASE(s) | 转小写 |
| LPAD(s, n, pad) / RPAD(s, n, pad) | 左/右填充 pad 到 n 位；s 超过 n 位则截断 |
| TRIM(s) / LTRIM(s) / RTRIM(s) | 去掉两端/左端/右端空格 |
| SUBSTRING(s, pos, len) | 截取子串，pos 从 1 开始，负数则从末尾数 |
| LENGTH(s) | 字符串**字节数**（UTF-8 下一个汉字 3 字节） |
| CHAR_LENGTH(s) | 字符串**字符数** |
| REPLACE(s, from, to) | 替换所有子串 |

```sql
SELECT CONCAT('Hello', ' ', 'MySQL');          -- Hello MySQL
SELECT LPAD('1', 5, '0');                      -- 00001（补工号常用）
SELECT SUBSTRING('Hello MySQL', 1, 5);         -- Hello
SELECT REPLACE('Hello MySQL', 'MySQL', 'SQL'); -- Hello SQL
```

## 二、数值函数

| 函数 | 说明 |
| ---- | ---- |
| CEIL(x) / CEILING(x) | 向上取整 |
| FLOOR(x) | 向下取整 |
| MOD(x, y) | 取模，等价于 x % y |
| ROUND(x, d) | 四舍五入保留 d 位小数，d 默认 0，可为负（处理个位以上） |
| TRUNCATE(x, d) | 截断到 d 位小数（不四舍五入） |
| ABS(x) | 绝对值 |
| RAND() / RAND(n) | 返回 0~1 随机数；带种子 n 时每次结果相同 |
| POW(x, y) / POWER(x, y) | 幂运算 |

```sql
SELECT CEIL(1.1);        -- 2
SELECT FLOOR(1.9);       -- 1
SELECT MOD(10, 3);       -- 1
SELECT ROUND(2.345, 2);  -- 2.35
SELECT RAND();           -- 0~1 之间，如 0.465034...
```

## 三、日期函数

| 函数 | 说明 |
| ---- | ---- |
| CURDATE() / CURRENT_DATE | 当前日期 |
| CURTIME() / CURRENT_TIME | 当前时间 |
| NOW() / CURRENT_TIMESTAMP | 当前日期和时间 |
| YEAR(d) / MONTH(d) / DAY(d) | 取年 / 月 / 日 |
| DATE_ADD(d, INTERVAL n unit) | 日期加一段时间，unit 可为 DAY / MONTH / YEAR / HOUR / MINUTE / SECOND |
| DATEDIFF(d1, d2) | 相差天数（d1 − d2，只算日期部分） |
| DATE_FORMAT(d, fmt) | 按格式化串转字符串 |
| STR_TO_DATE(s, fmt) | 按格式化串解析字符串为日期 |

常用格式符：`%Y` 四位年、`%m` 月、`%d` 日、`%H` 时、`%i` 分、`%s` 秒。

```sql
SELECT DATE_ADD(NOW(), INTERVAL 30 DAY);                 -- 30 天后
SELECT DATEDIFF('2026-09-10', '2026-09-01');             -- 9
SELECT DATE_FORMAT(NOW(), '%Y年%m月%d日 %H:%i:%s');      -- 2026年09月10日 21:30:00
SELECT STR_TO_DATE('2026-09-10', '%Y-%m-%d');            -- 2026-09-10
```

## 四、流程控制函数

| 函数 | 说明 |
| ---- | ---- |
| IF(cond, t, f) | 条件成立返回 t，否则返回 f |
| IFNULL(x, y) | x 不为 NULL 返回 x，否则返回 y |
| NULLIF(a, b) | a = b 返回 NULL，否则返回 a |
| CASE 表达式 | 分支逻辑，两种写法见下 |

```sql
SELECT IF(age >= 18, '成年', '未成年') FROM emp;

-- 逻辑等价于三元：空值兜底
SELECT IFNULL(phone, '未绑定') FROM emp;

-- CASE 写法一：switch 风格（判断city的值）
SELECT name,
       CASE city WHEN '北京' THEN '一线' WHEN '杭州' THEN '新一线' ELSE '其他' END AS 城市分级
FROM emp;

-- CASE 写法二：if-else if 风格（判断条件区间）
SELECT name,
       CASE WHEN salary >= 30000 THEN '高'
            WHEN salary >= 15000 THEN '中'
            ELSE '低' END AS 薪级
FROM emp;
```

CASE 是 SQL 中实现行转列（透视表）的基础手段。
