# MySQL 介绍

## 基本概念

- **数据库（Database）**：按照一定数据结构来组织、存储和管理数据的仓库，数据本身长期保存在计算机存储设备上。
- **数据库管理系统（DBMS）**：操纵和管理数据库的软件，负责数据的增删改查、安全与并发控制。
- **关系型数据库（RDBMS）**：以**表（Table）**为单位组织数据的数据库。每张表由行（记录）和列（字段）组成，表与表之间可以通过外键等建立关联。常见产品：MySQL、Oracle、SQL Server、PostgreSQL、SQLite。
- **非关系型数据库（NoSQL）**：不采用关系模型，如 Redis（键值型）、MongoDB（文档型）、Elasticsearch（搜索引擎）。

## SQL

SQL（Structured Query Language，结构化查询语言）是操作关系型数据库的标准语言，由 ANSI/ISO 标准化。SQL 是声明式语言：只描述「要什么」，不描述「怎么取」。

按照功能，SQL 通常划分为五类（本目录笔记即按此组织）：

| 分类 | 全称 | 说明 |
| ---- | ---- | ---- |
| DDL | Data Definition Language | 定义数据库对象（库、表、字段、索引、视图） |
| DML | Data Manipulation Language | 对表中的数据进行增、删、改 |
| DQL | Data Query Language | 查询表中的数据 |
| DCL | Data Control Language | 控制用户和权限 |
| TCL | Transaction Control Language | 控制事务（BEGIN / COMMIT / ROLLBACK） |

> 官方手册中不单独划分 DQL：`SELECT` 归类在 Data Manipulation Statements（13.2 节）下，事务语句单独成节（13.3 Transactional and Locking Statements）。

## MySQL 体系结构

MySQL 现属于 Oracle 公司，是一款开源的关系型数据库管理系统，采用**客户端/服务器（C/S）架构**：

- **客户端**：命令行工具 `mysql`，或图形化工具（Navicat、DataGrip、VS Code 插件等）。
- **服务器（mysqld）**：默认监听 TCP 3306 端口，接收客户端 SQL 并处理返回。服务器内部可分为：
	- **连接层**：管理连接、认证鉴权、线程池。
	- **服务层**：SQL 解析、优化、缓存、内置函数与跨存储引擎功能（如存储过程、触发器）。
	- **存储引擎层**：插件式架构，负责数据的实际存储与提取。可以通过 `SHOW ENGINES;` 查看支持的引擎。
	- **文件系统层**：数据、日志以文件形式落盘。

存储引擎特点对比（重点看两个）：

| 引擎 | 事务 | 行级锁 | 外键 | 适用场景 |
| ---- | ---- | ---- | ---- | ---- |
| InnoDB（默认） | 支持 | 支持 | 支持 | 需要事务、高并发的业务表 |
| MyISAM | 不支持 | 只有表锁 | 不支持 | 以读为主、不需要事务 |

> 详细对比与 InnoDB 内部结构见 [[web后端开发/数据库/MySql/存储引擎|存储引擎]]。

## 客户端连接

```bash
# -h 主机（本机可省略）-P 端口（默认3306可省略）-u 用户名 -p 密码（回车后输入）
mysql -h 127.0.0.1 -P 3306 -u root -p
```

连接后 `exit;` 或 `quit;` 退出。

## 数据模型

MySQL 是**层级**的数据模型：DBMS → 数据库（database，官方文档中也称 schema，二者同义）→ 表 → 行/列。一个数据库服务器上可以创建多个数据库，一个数据库中可以创建多张表。
