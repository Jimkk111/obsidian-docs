# Redis 介绍

## NoSQL

NoSQL（Not Only SQL）泛指非关系型数据库。与关系型数据库对比如下：

| 对比项 | 关系型（MySQL） | NoSQL（Redis） |
| ---- | ---- | ---- |
| 数据结构 | 表（行/列），结构固定 | 键值、文档、列族、图等，灵活 |
| 查询方式 | SQL，支持复杂关联（JOIN） | 命令/API，一般不支持 JOIN |
| 事务 | 完整 ACID | 弱事务或无事务（Redis 事务不支持回滚） |
| 扩展方式 | 纵向扩展为主 | 天然适合横向扩展 |
| 适用场景 | 强一致性、复杂查询 | 高并发读写、海量数据、可接受最终一致 |

NoSQL 常见分类：

| 分类 | 代表产品 | 典型场景 |
| ---- | ---- | ---- |
| 键值型 | **Redis**、Memcached | 缓存、会话共享 |
| 文档型 | MongoDB | 内容管理、日志 |
| 列族型 | HBase、Cassandra | 海量数据写入 |
| 图型 | Neo4j | 社交关系、推荐 |

> NoSQL 与关系型数据库是互补而非替代：实际项目常组合使用，如 MySQL 存业务数据 + Redis 做缓存（见 [[web后端开发/数据库/Redis/缓存|缓存]]）。

## Redis 简介

Redis（**Re**mote **Di**ctionary **S**erver，远程字典服务）是一款**基于内存的 key-value 数据库**，由 Salvatore Sanfilippo 开发，C 语言编写，BSD 开源协议（8.0 起开源版本称 Redis Open Source）。

核心特性：

- **基于内存**读写，性能极高（单机可达 10w+ QPS）。
- key 只能是字符串；value 支持**丰富的数据结构**：String、Hash、List、Set、ZSet，以及 BitMap、HyperLogLog、GEO、Stream。
- **可持久化**：RDB 快照 + AOF 日志，宕机后可恢复（见 [[web后端开发/数据库/Redis/持久化|持久化]]）。
- **高可用与横向扩展**：主从复制、哨兵、分片集群（见 [[web后端开发/数据库/Redis/主从与集群|主从与集群]]）。
- 功能丰富：key 过期、发布订阅、Lua 脚本、事务。

### 为什么快

1. **纯内存**操作，没有磁盘 IO。
2. 核心数据结构高效（跳表、哈希表、紧凑列表等，见各类型笔记）。
3. **命令执行单线程**：避免多线程的上下文切换和锁竞争，也不用考虑并发安全问题。
4. **IO 多路复用**（epoll）：单线程监听大量 socket 连接，谁就绪处理谁。

> - Redis 6.0 引入多线程，但**只用于网络 IO 的读写与协议解析，命令执行仍是单线程**。
> - 「单线程」指命令执行器；持久化、异步删除等重活由后台线程（BIO）完成。

### 应用场景

| 场景 | 说明 | 相关类型/笔记 |
| ---- | ---- | ---- |
| 缓存 | 热点数据放内存，减轻 MySQL 压力 | String / Hash，[[web后端开发/数据库/Redis/缓存|缓存]] |
| 计数器 / 排行榜 | 点赞数、播放量、销量榜 | String（INCR）/ ZSet |
| 分布式锁 | 集群环境下的互斥控制 | SET NX，[[web后端开发/数据库/Redis/分布式锁|分布式锁]] |
| 消息队列 | 异步、解耦、削峰 | List / Stream |
| 会话共享 | 集群节点间共享登录状态（Session） | String / Hash |
| 附近的人 | 位置服务 | GEO |

## 安装

Redis 官方只提供 Linux 版本，Windows 上推荐用 **Docker** 或 WSL2 运行。

```bash
# Docker 方式（Windows 推荐）
docker run -d --name redis -p 6379:6379 redis:latest --requirepass 123321

# 进入容器内交互
docker exec -it redis redis-cli -a 123321
```

Linux（Ubuntu）方式：

```bash
apt update && apt install -y redis-server   # 安装
redis-server /etc/redis/redis.conf          # 启动
```

## 连接

```bash
# -h 主机（本机可省略）-p 端口（默认6379可省略）-a 密码（redis.conf 中 requirepass 设置）
redis-cli -h 127.0.0.1 -p 6379 -a 123321
```

- 连接后执行 `PING`，返回 `PONG` 即连通。
- Redis 默认有 **16 个数据库**（编号 0~15，`databases 16` 配置），彼此隔离；`SELECT 1` 切换，`DBSIZE` 查看当前库 key 数量。**集群模式下只有 0 号库**。
- `exit` 退出。

## 客户端

- **命令行**：redis-cli。
- **图形化**：Another Redis Desktop Manager（免费开源）、RESP（原 Redis Desktop Manager）。
- **编程语言**：Java 的 Jedis、Lettuce、Redisson、Spring Data Redis，见 [[web后端开发/数据库/Redis/Java客户端|Java客户端]]。

客户端与服务端之间使用 RESP（REdis Serialization Protocol）文本协议通信，解析简单、可读性好。
