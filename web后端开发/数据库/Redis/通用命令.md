# 通用命令

通用命令针对 **key** 本身操作，与 value 类型无关。

## 常用命令

| 命令 | 示例 | 说明 |
| ---- | ---- | ---- |
| KEYS pattern | `KEYS user:*` | 查看符合模板的所有 key |
| SCAN cursor [MATCH pattern] [COUNT n] | `SCAN 0 MATCH user:* COUNT 100` | 渐进式分批遍历（生产推荐） |
| DEL key [key ...] | `DEL user:1` | 删除 key（同步） |
| UNLINK key | `UNLINK bigkey` | 异步删除（4.0+，后台线程回收内存，适合大 key） |
| EXISTS key [key ...] | `EXISTS user:1` | 判断是否存在，返回存在的个数 |
| EXPIRE key seconds | `EXPIRE code:138 120` | 设置过期时间（秒） |
| PEXPIRE key milliseconds | | 过期时间（毫秒） |
| TTL key | `TTL code:138` | 剩余过期时间：-1 永久，-2 不存在或已过期 |
| PERSIST key | | 移除过期时间，变为永久 |
| TYPE key | `TYPE user:1` | 查看 value 类型（string/hash/list/set/zset） |
| RENAME key newkey | | 重命名 |

```bash
127.0.0.1:6379> SET code:138 9527 EX 120
OK
127.0.0.1:6379> TTL code:138
(integer) 118
127.0.0.1:6379> PERSIST code:138
(integer) 1        # 成功移除过期时间
127.0.0.1:6379> TTL code:138
(integer) -1
```

### KEYS 通配符

| 符号 | 含义 |
| ---- | ---- |
| ? | 一个任意字符 |
| * | 任意个任意字符 |
| [ae] | 方括号中的任一字符 |

> **生产环境禁用 `KEYS *`**：一次性遍历全部 key 会长时间阻塞 Redis（单线程命令执行）。需要遍历时用 `SCAN`：每次返回新游标 + 一小批 key，分多次执行；缺点是期间 key 可能被修改（渐进式的代价）。

## key 命名规范

Redis 没有数据库「库-表」的概念，所有 key 共享一个键空间，只能靠命名区分业务。推荐：

```
[项目名]:[业务对象]:[id][:属性]
mall:cart:1001          # 用户 1001 的购物车（Hash）
mall:order:2026:1001    # 订单号
```

- 用冒号 `:` 分段是社区惯例，图形化客户端会按冒号分组树状展示。
- 见名知义，长短适中；同一系统大小写风格统一。
- 不要用特殊字符和空格。

## 库级命令

| 命令 | 说明 |
| ---- | ---- |
| SELECT n | 切换数据库（默认 0~15，集群模式只有 0） |
| DBSIZE | 当前库 key 数量 |
| FLUSHDB | 清空当前库（危险） |
| FLUSHALL | 清空所有库（危险） |
| INFO [section] | 查看服务器状态（memory、replication、stats 等） |
