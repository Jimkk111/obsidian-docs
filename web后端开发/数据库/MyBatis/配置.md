```plain

mybatis:
  #mapper配置文件
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.sky.entity
  configuration:
    #开启驼峰命名
    map-underscore-to-camel-case: true

```

`map-underscore-to-camel-case: true` 是 MyBatis 中的一个自动映射开关，它的核心作用是：允许数据库字段名（下划线命名）与 Java 实体类属性名（驼峰命名）之间进行自动匹配映射。Java实体类的字段名称一般是驼峰命名，而数据库的字段名是下划线命名，如果不开启这个自动映射开关，字段匹配不成功。
