MyBatis 是一款优秀的**持久层框架**，它支持定制化 SQL、存储过程以及高级映射。它通过简单的 XML 或注解来配置和映射原始类型、接口和 Java POJO（Plain Old Java Objects，普通老式 Java 对象）为数据库中的记录。

### 功能架构

- **API 接口层**：提供与数据库交互的 API，主要入口是 `SqlSession` 接口，开发者通过它来调用数据库操作。

- **数据处理层**：MyBatis 的核心，负责 SQL 的查找、解析、执行以及结果的映射处理。

- **基础支撑层**：为上层提供基础功能支撑，包括连接管理、事务管理、配置加载和缓存处理等。
