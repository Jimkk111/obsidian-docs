Spring 常用注解速查表，按用途分类。原理详解见 [[web后端开发/JavaWeb/springboot/spring/IoC和DI|IoC和DI]]、[[web后端开发/JavaWeb/springboot/spring/Bean管理|Bean管理]]。

## 组件声明（把类交给容器）

| 注解                | 作用                                                | 用在哪              |
| ----------------- | ------------------------------------------------- | ---------------- |
| `@Component`      | 声明一个类是 Bean，交给容器管理                                | 通用组件             |
| `@Service`        | 同上，语义为业务层                                         | Service 实现类      |
| `@Repository`     | 同上，语义为持久层                                         | Dao/Mapper 层     |
| `@Controller`     | 同上，语义为表现层                                         | 传统 MVC 控制器（返回视图） |
| `@RestController` | `@Controller` + `@ResponseBody`，返回 JSON           | **前后端分离项目都用它**   |
| `@Configuration`  | 声明配置类，里面用 `@Bean` 注册第三方对象                         | 配置类              |
| `@Bean`           | 标在方法上，返回值注册进容器，方法名即 Bean 名                        | 配置类中的方法          |
| `@ComponentScan`  | 指定扫描哪些包（`@SpringBootApplication` 已含，默认扫启动类所在包及子包） | 一般不单独用           |

> `@Component` / `@Service` / `@Repository` / `@Controller` 对容器**完全等价**，语义化命名只是给人看的。默认 Bean 名 = 类名首字母小写。

## 依赖注入（从容器拿 Bean）

| 注解 | 作用 | 备注 |
|---|---|---|
| `@Autowired` | 按类型自动注入 | 多个候选时配合下面两个消歧 |
| `@Qualifier("xxx")` | 指定 Bean 名 | 配合 @Autowired 用 |
| `@Primary` | 同类型多个时，标它的优先 | 加在实现类上 |
| `@Resource` | 先按名称注入，找不到再按类型 | JDK 标准（jakarta.annotation） |
| `@Value("${key}")` | 注入配置文件的值 | 支持 `${key:默认值}` |

推荐组合：**`@RequiredArgsConstructor` + `private final` 字段**（构造器注入，连 @Autowired 都省了）。

## 配置绑定（读 application.yml）

| 注解 | 作用 |
|---|---|
| `@ConfigurationProperties(prefix = "xxx")` | 批量把一组配置绑定到实体字段，支持松散绑定（`access-key-id` → `accessKeyId`）；类需配合 `@Component` |
| `@PropertySource` | 加载额外的 properties 文件（少用） |

## 生命周期与作用域

| 注解 | 作用 |
|---|---|
| `@Scope("prototype")` | 改作用域；默认 singleton（单例），prototype 每次获取新建 |
| `@PostConstruct` | Bean 创建且依赖注入完成后自动执行（初始化逻辑） |
| `@PreDestroy` | 容器关闭销毁前自动执行（释放资源） |

## AOP 与事务

| 注解 | 作用 |
|---|---|
| `@Aspect` | 声明切面类（配合 `@Component`，需 spring-boot-starter-aop） |
| `@Around` / `@Before` / `@After` / `@AfterReturning` / `@AfterThrowing` | 五种通知，详见 [[web后端开发/JavaWeb/springboot/spring/AOP]] |
| `@Transactional` | 声明式事务，**必须写 `rollbackFor = Exception.class`**，详见 [[web后端开发/JavaWeb/springboot/spring/事务管理]] |

## 条件装配（了解，自动配置的底层）

| 注解 | 作用 |
|---|---|
| `@ConditionalOnClass` | 类路径有指定类时才生效 |
| `@ConditionalOnMissingBean` | 容器没有该 Bean 时才生效（给默认实现留覆盖口） |
| `@ConditionalOnProperty` | 配置项满足条件时才生效 |

Spring Boot 自动配置的内部实现全靠这一族，业务开发很少直接用。

## Web 层注解

参数接收、请求映射等不在本篇，见 [[web后端开发/JavaWeb/springboot/spring-mvc/Controller|Controller]]。
