Spring Boot 的核心配置文件，放在 `src/main/resources` 下，名字固定为 `application`。

## 一、两种格式：properties 与 yml

`application.properties` 和 `application.yml` 二选一（同时存在时 properties 优先，别两个都写）。

```properties
# properties：扁平的 key=value
server.port=8080
spring.datasource.url=jdbc:mysql://localhost:3306/mydb
```

```yaml
# yml：缩进表示层级，更适合大量配置（推荐）
server:
  port: 8080
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mydb
```

**yml 语法要点**：

1. `key: value`，**冒号后必须有一个空格**，没有空格就是普通字符串
2. 用缩进表示层级，**只能用空格，不能用 Tab**，同级元素左对齐
3. 大小写敏感
4. 值的写法：
   - 字符串默认不加引号；数字/布尔直接写；空值用 `~` 或不写
   - 双引号会处理转义（`"a\nb"` 输出换行），单引号不处理（`'a\nb'` 原样输出）
5. 对象与数组：

```yaml
user:
  name: 张三
  age: 18
  hobby:              # 数组写法一：每行一个 -
    - 篮球
    - 游戏
address: [北京, 上海]   # 数组写法二：行内
```

## 二、常用配置项

```yaml
server:
  port: 8080                      # 端口
  servlet:
    context-path: /api            # 统一前缀，接口变成 /api/xxx

spring:
  datasource:                     # 数据源（整合 MyBatis 必备）
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/mydb
    username: root
    password: 123456

mybatis:
  mapper-locations: classpath:mapper/*.xml     # XML 的 SQL 文件位置
  configuration:
    map-underscore-to-camel-case: true         # 下划线转驼峰：create_time -> createTime
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl   # 控制台打印 SQL（开发期用）

logging:
  level:
    com.example.demo.mapper: debug             # 指定包的日志级别
```

## 三、读取配置

### 1. @Value：读单个

```yaml
aliyun:
  bucket: my-bucket
```

```java
@RestController
public class UploadController {
    @Value("${aliyun.bucket}")          // 引用 yml 里的值
    private String bucket;

    @Value("${aliyun.timeout:30}")      // 冒号 = 默认值，配置不存在时用 30
    private int timeout;
}
```

### 2. @ConfigurationProperties：批量绑定到实体

配置多的时候，逐个 @Value 太啰嗦，直接绑定到一个类：

```yaml
aliyun:
  bucket: my-bucket
  endpoint: oss-cn-hangzhou.aliyuncs.com
  access-key-id: xxx
  access-key-secret: yyy
```

```java
@Component                            // 1. 必须注册成 Bean，Spring 才会帮你绑定
@ConfigurationProperties(prefix = "aliyun")   // 2. 前缀对齐
@Data                                 // 3. 必须有 setter（@Data 生成）
public class AliyunProperties {
    private String bucket;
    private String endpoint;
    private String accessKeyId;       // 松散绑定：access-key-id 自动映射到 accessKeyId
    private String accessKeySecret;
}
```

用的时候直接注入整个对象：

```java
@RestController
@RequiredArgsConstructor
public class UploadController {
    private final AliyunProperties aliyunProperties;

    @GetMapping("/test")
    public String test() {
        return aliyunProperties.getBucket();
    }
}
```

### 3. 两者怎么选

| | @Value | @ConfigurationProperties |
|---|---|---|
| 场景 | 一两个零散的值 | 一组有前缀的配置 |
| 松散绑定 | 不支持 | 支持（kebab-case 自动驼峰） |
| 附带能力 | SpEL 表达式 | 校验、元数据提示 |

## 四、多环境配置

开发连本地库、上线连生产库，靠的是 profile 机制：

```
application.yml           # 公共配置 + 激活哪个环境
application-dev.yml       # 开发环境
application-test.yml      # 测试环境
application-prod.yml      # 生产环境
```

```yaml
# application.yml 里指定当前生效的环境
spring:
  profiles:
    active: dev        # 改成 prod 就整套切到生产配置
```

打包后不想改文件，启动时命令行覆盖：

```bash
java -jar app.jar --spring.profiles.active=prod
```

## ⚠️ 常见坑

1. **yml 冒号后没空格** → 值读不到或直接启动报错，IDEA 里 key 部分变色了才算对
2. **@ConfigurationProperties 绑定不上** → 忘了 `@Component`（或在配置类上加 `@EnableConfigurationProperties(AliyunProperties.class)`）
3. **properties 中文乱码** → IDEA 默认编码问题（Settings → File Encodings 全改 UTF-8）；用 yml 一般没这个问题
4. **配置不生效** → 确认文件在 `src/main/resources` 根下、名字是 `application`；改完要重启
5. **密码等敏感信息** → 不要提交明文到 git，可用环境变量引用：`password: ${DB_PASSWORD}`
